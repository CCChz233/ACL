# 研究计划：Evidence-Efficient Harness Self-Improvement

更新：2026-10-20。当前唯一故事以 [research_story.md](research_story.md) 为准，深化实验详见 [evidence_research_agenda.md](evidence_research_agenda.md)。先分析证据作用，再设计读取策略。旧“模型比较—组件替换—瓶颈蒸馏”及更早的 Solver/Trainer 计划均已退出执行主线。

## 固定组合

- Task Agent：mini-SWE-agent，保留现有版本；审计 HarnessFix 内嵌版本的差异后冻结适配。
- Benchmark：SWE-bench；现有 Mini50 用于工程、成本审计和开发，不作为新方法的未见测试。
- 优化模型与执行模型：DeepSeek Flash，配置固定。
- 第一套系统：HarnessFix；第二套核心验证：Meta-Harness。
- 方法对象：优化器读取的轨迹、源码、修改历史；不改变 RSI 核心进化算法。
- 暂定实现代号：Edit-Aware Evolution Context；不预设其新颖或有效，先进行证据可用性与粒度干预。

DGM、Harness² 不进入首阶段。当前不进行模型能力排名、SFT/LoRA/RL 或 Qwen 定向蒸馏；ACON 的准则优化成本要计入，若比较其蒸馏版本则另列训练资源。

Meta-Harness 原生访问本就支持按需检索；CIG 原生系统涉及规划和组合选择，context-only 适配须明确标注，系统级比较另列。先完成与上述工作的机制矩阵，不把结构化历史、图和自动进化本身当作空白。

## 预注册与费用边界

实际开跑前冻结：模型配置、H₀ 与编辑范围、框架版本、数据 split、快照来源和截止点、随机种子、候选/轮数、执行与选择规则、各类调用及总 token/费用上限、有效修改与回归定义、非劣界限和统计方案。旧运行预算不自动延续到新框架。

两种主比较分别回答不同问题：固定候选和评测数量看上下文净节约；固定包含组织器开销的总 token 看相同资源下的最终质量。不得通过少跑候选、提前失败或遗漏摘要成本宣称效率提升。

复用原始轨迹的配对实验先行，不同时启动四套漫长独立搜索。后续完整 RSI 必须独立重复；来自同一次历史搜索的多个快照不能冒充独立搜索。正式测试不可参与方法、阈值或候选选择。
